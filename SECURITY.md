# Security and Privacy

EqualPath handles availability and care-related planning data. Please do not open public issues containing credentials, OAuth tokens, personal health information, live Appwrite identifiers tied to a person, or unredacted screenshots of private data.

For this academic Iteration 1 repository, report a security concern privately to the repository owner through their GitHub profile. Include only the minimum information required to reproduce the issue safely.

The automated workflows in this repository validate and package the frozen source snapshot. They do not deploy to the live Appwrite environment or mutate live owner data.
